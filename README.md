Responsive Portfolio Website
This project is a responsive personal portfolio website developed using HTML, CSS, and Bootstrap. It is designed to showcase personal information, technical skills, projects, and contact details in a professional and user-friendly manner.

Features
Responsive design for mobile, tablet, and desktop devices
Attractive landing page
Smooth scrolling navigation bar
Skills section
Projects showcase section
Contact form
Modern and clean UI
Technologies Used
HTML5
CSS3
Bootstrap 5
Project Objective
The objective of this project is to create a professional portfolio website that demonstrates front-end web development skills and provides an online presence for showcasing projects and achievements.
